# Проект репрозитория для практическойработы №4
В данном репозитории будут хранится файлы, которые будут необходимы во время исполнения практической работы №4.

## Инструкция по установке
1. Открыть папку в терминале;
2. Ввести команду для клонирования репозитория
```
git clone https://github.com/LokiMATI/TRPO-LabWork4.git
```

## Использование
В данном репозитории можно исполнять любые команды GIT.

## Системные требования
- Windows 10;
- iCore 3;
- 16 ГБ ОЗУ;
- 20 ГБ HDD/SSD.
